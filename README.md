# JavaScript DOM and Event Handling

## Project Description

This project is a simple interactive web page created using **HTML, CSS, and JavaScript**.

The project demonstrates the use of the **DOM (Document Object Model)** and **Event Handling** in JavaScript.

The webpage contains:
- A greeting header
- Four color boxes: Red, Blue, Green, and Yellow
- An input field for entering the user's name
- A Greet button

Initially, all color boxes are white. When a user clicks on a particular box, the box changes to its respective color.

When the user enters their name and clicks the **Greet** button, the header changes from **"Hello"** to **"Hello, [Name]"**.
